# AWS Cloud Infrastructure Project

## Project Overview

This is a hands-on AWS learning project focused on building and understanding basic cloud infrastructure using Amazon Web Services.

## Objectives

* Understand AWS VPC and subnet configuration
* Learn public and private subnet concepts
* Configure EC2 security groups
* Understand Internet Gateway and route tables
* Practice S3 static website hosting
* Develop basic cloud troubleshooting skills

## AWS Services

* Amazon VPC
* Amazon EC2
* Amazon S3
* Security Groups
* Internet Gateway
* Route Tables

## Architecture

The planned architecture includes an AWS VPC with public and private subnets, an EC2 instance, and an S3 website or file-hosting component.
## Implementation Steps

1. Created a VPC and explored subnet configuration.
2. Practiced public and private subnet concepts.
3. Configured EC2 networking and security group rules.
4. Practiced S3 static website or file hosting.
5. Tested connectivity and investigated configuration errors.

## Troubleshooting Notes

Document real issues encountered during the project, such as:

* S3 website errors such as 404 Not Found or NoSuchKey
* Incorrect object paths and file names
* Security group and routing configuration issues

Add the actual cause and fix for each issue after verifying it.

## Security Considerations

* Restrict inbound access to required ports.
* Avoid exposing private resources to the public internet.
  
## Skills Practiced

AWS fundamentals, cloud networking, EC2, VPC, S3, security groups, and troubleshooting.
